### Phase D — deterministic rebuild

- Rebuild the PNG from the canonical source using the documented command.
- Prefer no network during rebuild. If a dependency is required, pin and document it.
- Ship every render dependency. Use pinned, license-safe font files; record font-file hashes, license, actual font resolution, and renderer version. Prohibit absolute paths, unresolved linked images, network resources, and external CSS. Check duplicate SVG IDs and broken fragment references.
- In a separate clean checkout without Project Context or developer caches, remove only the enumerated generated outputs and regenerate them without network access. The build must fail nonzero on missing input or renderer failure; a successful no-op or reuse of the committed PNG is not a rebuild.
- Confirm regenerated outputs decode and match the committed output by the documented comparison method. Define whether each checksum covers source bytes, render bytes, or decoded pixels.
- Open the delivered SVG in a second viewer and check images, glyphs, wrapping, masks, clipping, and margins. If an outlined portable derivative is useful, keep the editable-text source authoritative.
- Store SHA-256 checksums for source and render in `manifest.json`.

### Phase E — real pixel QA

Inspect the actual PNG, not SVG text or a verbal description. The whole poster plus overlapping readable crops must cover every panel:

1. whole-poster/thumbnail scale;
2. normal poster-reading scale;
3. 100% detail crops.

At thumbnail scale verify that a viewer finds the question, the retinal two-leg object, the measured/inferred/unknown distinction, and U2.

At normal scale verify reading path, hierarchy, density, typography, contrast, evidence-status encoding, and that supporting material does not compete with the hero.

At detail scale verify numbers, units, construct identity, captions, labels, alignment, clipping, margins, and provenance.

Record the inspected render checksum, crop coordinates, coverage map, physical text sizes, and concrete findings in `qa_report.md`. A visual PASS is invalid if it refers only to source text, an automatically downsampled whole image, or incomplete crop coverage.
